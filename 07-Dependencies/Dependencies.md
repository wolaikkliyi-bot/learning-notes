# 依赖与库说明（Dependencies）

本文件夹用于整理项目中涉及的**第三方依赖、动态库（DLL）、运行时资源以及部署**相关的内容，
帮助快速定位“缺少某个文件 / 版本不匹配 / 部署漏拷”等问题。

## 包含内容

- Qt 各模块依赖的 DLL 与资源文件（如 WebEngine）。
- 使用 `windeployqt` 进行自包含部署的说明。
- 常见“找不到 xxx.dll”“版本冲突”问题的排查思路。
- 其他第三方库的安装、版本与路径约定。

## 记录约定

- 每个依赖问题尽量标注：**现象关键词、涉及版本、解决步骤**。
- 涉及路径时保留完整路径，方便直接复制使用。
- 优先推荐自包含部署（把依赖拷到程序目录），避免依赖系统 `PATH`。
