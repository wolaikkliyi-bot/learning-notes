# 语法
## 一、标题
Markdown两种标题格式
### 1、=和-
```
一级标题
=======
二级标题
-------
```
### 2、#标题
```
# 一级
## 二级
...
```

## 重要注意事项

- **符号与文字之间的空格**

  `#` 号和标题文字之间必须有一个空格。


- **行首位置**

  `#` 号必须在行首，前面不能有其他字符（空格或制表符）。


- **唯一的一级标题**

  一个文档通常只使用一个一级标题作为文档主标题。

- **标题锚点**  

  大多数 Markdown 处理器会自动为标题创建锚点（anchor），便于页面内跳转  
  ```
  [跳转到方法论部分](#方法论)
  ```
