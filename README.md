# 工具使用与问题记录

本仓库用于整理开发中常用工具的**使用方法**，以及实际使用过程中**遇到的问题与解决方案**。
内容以 Markdown 记录，便于检索、版本管理和随查随用。

## 目录索引

| 序号 | 目录 / 文件 | 说明 |
| ---- | ----------- | ---- |
| 01 | [01-markdown](./01-markdown/) | Markdown 语法与书写笔记 |
| 02 | [02-git](./02-git/) | Git 常用命令速查（提交、分支、远程、密钥） |
| 03 | [03-GDB](./03-GDB/) | GDB 调试命令速查 |
| 04 | [04-venv](./04-venv/) | Python 虚拟环境（venv）常用命令 |
| 05 | [05-Qt](./05-Qt/) | Qt 版本管理、编译环境与部署相关问题 |
| 06 | [06-TortoiseGit](./06-TortoiseGit/) | TortoiseGit 图形化使用笔记 |
| 07 | [07-Dependencies](./07-Dependencies/) | 依赖与库（DLL / 资源 / 部署）相关说明 |
| - | [使用解决问题.md](./使用解决问题.md) | 实际踩坑与解决方案汇总 |

## 记录约定

- 每个工具一个编号文件夹，新增工具时按顺序追加编号。
- 问题记录统一在文件开头标注记录日期、环境、标签，便于判断是否过时。
- 笔记尽量保留**报错现象关键词**，方便全文搜索定位。
